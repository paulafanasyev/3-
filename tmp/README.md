# Черновые замерщики

Одноразовые пробы, которыми измерялись взрыв, кольца, купол грунта, зум и пищалка запрета.
Это не часть игры и не часть `npm test`: их запускал автор с конкретной машины, поэтому пути
(`D:/mt5/tmp-nuclear`, Chrome) в них зашиты под неё. Лежат здесь как доказательство замеров,
цитаты из которых стоят в `docs/game/CORE.md`.

Постоянные замерщики с настройкой через окружение (`KUPOL_QA_OUT`, `PUPPETEER_EXECUTABLE_PATH`) —
в `scripts/`. Профили браузера (`chrome-profile*/`) в git не входят: это данные Chrome, а не проекта.
