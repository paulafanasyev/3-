# src/game — ядро «Купола»

Пошаговая стратегия на настоящей Земле с вымышленной политической картой. Вся логика здесь,
на сервере; клиент только рисует снимок и отправляет команды. Правила: `docs/game/DESIGN.md`,
отличия реализации и баланс: `docs/game/CORE.md`.

| Модуль | Что делает |
|---|---|
| `grid.js` | Геодезическая сетка (10 242 ячейки) |
| `map.js` | Загрузка `data/game/map.json`, обход соседей |
| `worldgen.js` | Вымышленные провинции, народы, города, имена, стартовые зоны |
| `names.js` | Генератор имён и защита от совпадений с реальными |
| `state.js` | Создание партии, индексы, снимок с туманом войны, хеш |
| `rules.js` | Доходы, бой, пути, видимость |
| `commands.js` | `applyCommand` — единственный способ изменить партию |
| `turn.js` | `endTurn` — экономика, наука, движение, финал, победа |
| `diplomacy.js` | Договоры, репутация, оценка предложений |
| `finale.js` | «Немезида»: пакт, Ковчег, итог |
| `ai.js` | ИИ через те же команды |
| `session.js` | WebSocket-протокол `game:*` |

Всё детерминировано: случайность только из `rng.js`, обход объектов в фиксированном порядке.
